## 🎓 How to Learn (Daily Schedule)

### **Daily Routine (3-4 hours)**

1. **Theory (30-45 min)**
   - Read THEORY.md in the module folder
   - Understand concepts
   - Take notes

2. **Code Examples (30-45 min)**
   - Study example programs
   - Modify & experiment
   - Trace through execution

3. **Practice (90-120 min)**
   - Solve exercises
   - Write code from scratch
   - Debug & optimize

4. **Review (15-30 min)**
   - Revisit today's concepts
   - Plan tomorrow's learning

### **Weekly Review**
- Revise previous week's concepts
- Attempt harder problems
- Create summary notes

## 💫 Pro Tips for Success

1. **Code Every Single Day** - Even 30 mins daily > 5 hours once a week
2. **Debug Manually First** - Use printf() before GDB
3. **Write Notes** - Handwriting helps memory retention
4. **Teach Others** - Explain concepts to solidify understanding
5. **Contribute to GitHub** - Push your solutions to GitHub
6. **Read Others' Code** - Learn from open-source projects
7. **Join Communities** - Reddit r/learnprogramming, Discord servers
8. **Do Code Reviews** - Review and critique your own code
