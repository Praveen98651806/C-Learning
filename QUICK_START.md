## Daily 3-Hour Routine

**This is what you should do EVERY DAY:**

### 9:00 - 9:45 AM: Theory (45 min)
- Read THEORY.md for the current topic
- Take handwritten notes
- Draw diagrams
- Ask "Why?" for every concept

### 9:45 - 10:30 AM: Code Examples (45 min)
- Study provided `.c` files
- Predict output before running
- Compile and run
- Modify and test

### 10:30 - 12:00 PM: Practice (90 min)
- Solve exercises
- Write code from scratch
- Test thoroughly
- Debug errors

### 12:00 - 12:15 PM: Review (15 min)
- Summarize what you learned
- Identify weak areas
- Plan tomorrow's topics
